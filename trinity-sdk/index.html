Architecture layers
Core
createApp.js
sync.js
persist.js
The non-negotiable foundation. Pure reduce + append-only log.
Transport
webrtc.js
websocket.js
local.js
Pluggable sync layer. Swap without touching app logic.
CRDT
crdt-text.js
RGA-style text. Runs inside reduce(). Conflict-free by construction.
Presence
presence.js
Ephemeral layer. Never logged. Bypasses the deterministic log entirely.
AI
runner.js
Non-deterministic boundary is at the API call. Results enter the log.
